
# FoodDelivery SQL Project

## About the Project

I am building this project to improve my SQL skills and get more
comfortable with database design and real-world SQL problems.

For this project, I am creating a small food delivery database
with information about customers, restaurants, menu items, orders,
payments and deliveries.

I will build the database step by step and use SQL to answer
different business questions.

## What I am Practicing

- Database design
- Primary keys and foreign keys
- INSERT, UPDATE and DELETE
- Filtering and sorting data
- GROUP BY and HAVING
- JOINs
- Subqueries
- CTEs
- Window functions
- Date functions
- CASE statements
- Data cleaning
- Query optimization

## Some Questions I Want to Answer

- Which restaurants have the highest sales?
- Which customers place the most orders?
- Which city has the most orders?
- What is the average order amount?
- Which food items are ordered the most?
- How many orders are cancelled?
- Which delivery partners complete the most deliveries?
- How does sales change month by month?
